Fly the Petrel SK-2 bush plane over a temperate archipelago. Dispatch five sorties from three airfields. Run eight survey gates, deliver the post, scoop and drop water, find a stranded hiker, or land at Gullhaven in a dusk crosswind. Fuel, airframe damage, and touchdown quality carry through to the debrief.

Run `node serve.ts` with Node.js 22.18+, then open `localhost:8080` in desktop Chrome. The game uses local files and synthesized audio.

| Control | Action |
| --- | --- |
| W / S, A / D, Q / E | Pitch, roll, rudder |
| Shift / Ctrl or scroll | Increase / decrease throttle |
| F / V, G, B | Extend / retract flaps, toggle gear, toggle brakes |
| C, mouse drag | Switch camera, look around |
| Space, Esc, R, M | Mission action, pause, restart, mute |

For takeoff, advance the throttle and hold W when the airspeed passes 50 kt. Start easing off W after liftoff. Refuel on any runway by stopping with brakes on and throttle idle.
